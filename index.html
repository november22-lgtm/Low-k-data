각도 계산 방법

Sidewall의 수평 이동량 ΔCD와 식각 깊이 Depth를 이용합니다.

θ = 90° − arctan(ΔCD / Depth)

계산 Angle

Depth와 Top/Bottom CD 차이를 이용해 자동 계산합니다. 자동 계산값은 필요하면 직접 수정할 수 있습니다.

θ = 90° − arctan((|Top CD − Bottom CD| / 2) / Depth)
